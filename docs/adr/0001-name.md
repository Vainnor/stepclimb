# 0001. Name: Stepclimb

- **Status:** Accepted
- **Date:** 2026-11-12
- **Decider:** the owner, in the plan v1.0 (12 Nov 2026), Technical -> Decided
- **Related:** `docs/plan/README.md`

## Context

The project needed a name that is not tied to VATSIM or vZDC, since the plan makes it a
general-purpose learning platform for any organization.

## Decision

The project is **Stepclimb**. Crates are `stepclimb-*`, the binary is `stepclimb`, packages are
`@stepclimb/*`, configuration variables are `STEPCLIMB_*`, and the session cookie is
`__Host-sc_session` (`sc` prefix, as the plan's token and CSS names use).

## Consequences

Trademark clearance, domains and handles are not part of the plan's decision and are not
covered here; an ADR records them if the owner takes them up.
