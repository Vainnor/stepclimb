# M4 Integrations and pilot readiness

- **Milestone:** M4, weeks 11 to 14

The public integration surface and what the vZDC pilot needs to start: the sync API for users
(with managers), groups and role assignments, and SCIM 2.0; permission modes (group-mapped,
pushed, delegated); the reporting API with `updated_since` cursors, bulk exports to download or
to the organization's own S3 bucket, and the compliance report; Standard Webhooks from the outbox
with a delivery log and replay; the VATSIM and VATUSA connectors on the public API; enrollment
rules; the course archive; organization export, import and per-organization restore; per-user
data export and deletion; Web Push; point-in-time backups with WAL archiving and the restore
drill in CI; Prometheus metrics; the docs site (admin, author, API and self-hosting guides,
replacing `deploy/compose/README.md`). The dedicated security review before the pilot belongs
here. The vZDC pilot starts at the end of M4.

Plan: `docs/plan/technical.md` -> Integration platform, Identity and access (Provisioning),
Tenancy and structure (reporting lines), Progress and grades (Compliance report), Hosting and
operations (Backups, Operations), Security and privacy, Data model (platform tables), API
surface, How it's built (security review), vZDC deployment, Milestones; `docs/plan/ui.md` ->
Component inventory (Learning: ComplianceTable, AssignmentList).

Full spec: written before M4 starts.
