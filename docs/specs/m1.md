# M1 Learning

- **Milestone:** M1, weeks 2 to 5

Courses, modules and items (page, video, file, quiz, activity, external link or header) with
prerequisites, unlock dates, sequential completion and completion requirements; pages edited in the
Tiptap editor and versioned; video, both uploaded (tus uploads, ffmpeg transcode to HLS and MP4,
captions, chapters, signed delivery) and linked (YouTube, Vimeo, oEmbed, direct URLs), with watch
tracking for both; files stored once per SHA-256 and served through signed URLs; progress per user
and item rolled up to module and course, with `item.completed`, `module.completed` and
`course.completed` events; the learner dashboard with Next up; announcements; email from the
platform sender and from organization senders, with editable templates and preferences. Assignments
with fixed or relative due dates, reminders and escalation, recurrence and expiring completions.
Deep links (`/c/:course/m/:module/i/:item`) with a return URL. The installable web app with offline
reading. The UI work is the Learning row of the component inventory (ProgressRail, PageReader and
the rest), the M1 part of Forms and Data, the M1 part of Authoring, and VideoPlayer and
VideoUploader. The one-week Tauri iPhone test runs in this milestone; if it fails, the iPhone app
moves to Expo (ADR 0011).

Plan: `docs/plan/technical.md` -> Courses and content, Progress and grades (Due dates,
recurrence and expiry), Email and notifications, Integration platform (Embedding, Content in),
Web app and native apps (Web app, iPhone test), Data model (learning tables), API surface,
Milestones; `docs/plan/ui.md` -> Component inventory (Learning, Forms, Data, Authoring,
Activities: VideoPlayer and VideoUploader), Signature components (ProgressRail, PageReader), Key
layouts.

Full spec: written before M1 starts.
