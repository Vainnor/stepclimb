# Third-party code in Stepclimb UI

Code adapted from other component libraries keeps its license notice here (`docs/plan/ui.md` ->
What we borrow: shadcn/ui, Kibo UI, AlignUI, Magic UI, Libraries.dev, InstUI, Immich UI, all MIT).
Each row names the file the code went into, the source it came from, its license and the notice
copied from that source. The PR that adapts the code adds the row.

None has been adapted yet: `Button` is the plan's own convention example.

Packages installed as dependencies are not adapted code and are not listed: their license travels
with the package in `node_modules`. Stepclimb UI's are `@phosphor-icons/react` (MIT), drawn
through `Icon`, and the `@fontsource` fonts the apps load (OFL-1.1).
